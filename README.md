
# Dare

A simple, playful dare web app built with **React**, **Vite**, and **Tailwind CSS**.

No account. No sign-up. No backend.

Just open the app, click **Give Me a Dare**, and see what you get.

## ✨ Features

* 🎲 Randomly picks a dare from the dare collection
* 🔁 Prevents recently shown dares from repeating
* 🧹 Small **Clear History** option in the footer
* ✨ Animated dare cards and interactive buttons
* 📱 Responsive design for mobile, tablet, and desktop
* ⚡ Fully client-side — no backend or database required
* 🔐 No authentication or user accounts


## 🎨 Design

The interface is intentionally minimal.

The main experience focuses on:

```text
OPEN APP
   ↓
GIVE ME A DARE
   ↓
DARE APPEARS
   ↓
NEXT
   ↓
ANOTHER DARE
```

The UI uses subtle animations to make the experience feel playful without overwhelming the user.
